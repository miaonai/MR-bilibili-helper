# MR哔哩哔哩助手 - forked from [MortRex](https://greasyfork.org/zh-CN/scripts/445241)

#### 这是一个修改哔哩哔哩布局并增加额外功能的脚本，愿你打造出属于自己的哔哩哔哩，Enjoy it ~

- 菜单可以向下滚动，别傻傻的盯着截断的菜单看啦！
- 按住菜单任意位置可以拖拽菜单，刷新或重新打开网页会重置位置到中心，不用担心把菜单拖出窗口~
- 抓虫指南：发现问题时先按F12打开开发者工具，看看是否有“userscript...”的错误，如果没有看看你想用的功能是否输出了log，我把每个功能执行后都写了log，如果没有相关功能的log请反馈给我。
- 我平常是用Tampermonkey和Edge浏览器，其他脚本平台和浏览器可能会有适配问题，见谅，如有问题请反馈，我会尽量适配的~
- 本脚本已采用[MIT协议](LICENSE)完全开源，代码中有完整注释，你可以基于本脚本毫无顾虑自由的改造/发布属于你的脚本啦。

---
# 功能

1. 播放器模式：默认模式、自动宽屏模式、网页全屏模式，随心所欲。
2. 自定义布局：海量布局，随意搭配，打造属于你的布局
3. 实用功能与工具：大量实用功能，提升视频观看体验
